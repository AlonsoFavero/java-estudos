# ☕ Java Estudos

Repositório dedicado ao meu processo de aprendizagem em **Java**, com exercícios práticos, exemplos de código e aplicação dos principais conceitos da linguagem.

O objetivo deste projeto é consolidar os fundamentos necessários para minha formação como **Desenvolvedor Backend Java**.

---

## 🎯 Objetivos

* Consolidar os fundamentos da linguagem Java
* Praticar **Programação Orientada a Objetos (POO)**
* Entender e aplicar Collections e Streams
* Trabalhar com tratamento de exceções
* Desenvolver código mais organizado e reutilizável
* Criar uma base sólida para projetos Backend
